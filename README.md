# UPMIO ClickHouse Hackathon

This repository stores the public hackathon materials for the UPMIO ClickHouse
operations project.

The `exam/` directory is intentionally excluded because it contains competition
attachments and score documents that should not be published.

Source-code changes are committed in the corresponding UPMIO repositories:

- `upm-packages`: `phase-01` branch in the maintained fork.
- `unit-operator`: `phase-01` branch in the maintained fork.
- `compose-operator`: tracked as a forked upstream dependency; no Phase 01 code
  change was required.

The hackathon evidence and acceptance assets are under `docs/` and
`clickhouse/`.

Clone with submodules when inspecting source links:

```bash
git clone --recurse-submodules <repo-url>
```
